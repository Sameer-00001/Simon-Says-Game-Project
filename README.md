# Simon-Says-Game-Project
This is a game to improve your brain memory.

## Description
The Simon Says Game is a fun and interactive memory game that challenges players to remember and repeat a sequence of colors. The game starts with a simple sequence of colors that light up, and as the player successfully repeats the sequence, it becomes longer and more challenging. The objective is to see how long you can keep up with the increasing difficulty and test your memory skills.

## Features
- Colorful and engaging interface.
- Increasing difficulty with each round.
- Simple and intuitive gameplay.

## Instructions
1. Open the `index.html` file in your web browser.
2. Follow the on-screen instructions to play the game.
3. Enjoy and have fun testing your memory skills!
4. You can also customize the game by modifying the CSS and JavaScript files to change the colors, sounds, or difficulty levels.

## How to Play
1. Click the Any button on your keyboard to begin the game.
2. Watch the sequence of colors that light up.
3. Repeat the sequence by clicking the colors in the same order.
4. Each round adds one more color to the sequence.
5. If you make a mistake, the game ends and you can restart.
